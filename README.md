- **Эконометрическое моделирование эластичности полки и каннибализации:** построила регрессионные модели оценки эластичности продаж от доли полки и межсегментной каннибализации ассортимента (Python, statsmodels, scikit-learn); устранила мультиколлинеарность с метриками дистрибуции и наличия товара, сформировав рекомендации по оптимизации матрицы без потери совокупной выручки категории.
